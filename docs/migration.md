# Переход от исходного каркаса

Изменение намеренно несовместимо с неподтверждённым API базового коммита
`1737ca4448a43b05f1f56b1a2f82e19a2cf14255`.

| Ранее | Теперь | Причина |
|---|---|---|
| `T11_Finite`, `T11_Infinite` | `T11` и `AtomPartition` | Конечная булева грамматика не требует конечного носителя; бесконечные соединения не заявляются |
| `T12` о декартовой замкнутости | `T12` об идеальном пополнении | Соответствие теореме 1.2 научной редакции |
| `T21` со смешанными предпосылками | Наблюдаемые контракты; отдельно `T22` | Различение композиции и совместной выполнимости |
| `IsModel = True` | Удовлетворение включениям TBox | Содержательная семантика |
| Аксиомы о полной решётке всех концептов | Булева алгебра и отдельное идеальное пополнение | Полнота не предполагается заранее |
| Успех при отсутствии SHACL/SPARQL-файлов | Ошибка или отказ | Нельзя принимать непроведённую проверку |
| REST/gRPC и Akka-каркас с несовместимыми сообщениями | Локальная библиотека и CLI | Сначала воспроизводимый исполняемый контур; прежний интерфейс не был согласован |
| Онлайн-обучение/сходство как основание исполнения | Кандидат, свидетельства, согласование, выпуск | Разделение функций по монографии |
| Манифесты Kubernetes/Terraform и k6 | `design/legacy/`, не участвует в сборке | Не соответствует текущему CLI; не является развёрнутой инфраструктурой |
| Заявленные DOI, согласования и SLA | Проверяемые метаданные и явные ограничения | Свидетельства отсутствовали |

Старый исходный код полностью сохраняется в истории Git. Инфраструктурные
эскизы дополнительно сохранены локально в `design/legacy/`, чтобы последующая
реализация могла использовать их после пересмотра. Откат выполняется средствами
Git, а не путём смешения старых и новых модулей.

Перед промышленным API нужны независимая спецификация, идентификация и
авторизация, модель угроз, ограничение ресурсов, журнал доказательств,
хранилище выпусков, отмена/отзыв, контроль повторов и неизвестного исхода,
контракт ошибок, восстановление и испытания на согласованной нагрузке.
