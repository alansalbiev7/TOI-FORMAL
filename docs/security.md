# Границы доверия

Текущая версия предназначена для локального исследования с синтетическими данными.
Она не реализует аутентификацию, юридически значимую электронную подпись,
защиту государственных информационных систем либо аттестацию.

Формы и запросы должны поступать от доверенного разработчика и проходить review.
Хеш подтверждает идентичность байтов при сравнении, но не подлинность автора,
полномочия и истинность сведений. Утверждение «все проверки пройдены» имеет смысл
только вместе с известной областью проверок и привязкой к версиям.

Локальный SELECT не допускает `FROM`/`SERVICE`; глубина и ресурсы обработки
сложного RDF/SHACL этим полностью не ограничиваются. Для недоверенных входов
требуются изоляция процесса, лимиты памяти/времени, аудит разрешённых
конструкций и отдельное проектирование парсинга. Текущий лабораторный API
не предназначен для публичного исполнения произвольных правил; SHACL-SPARQL/JS не поддерживаются.

Не помещайте персональные данные, ключи или пароли в Git, примеры и тесты.
При обсуждении дефекта достаточно минимального синтетического примера.
Автоматический анализ зависимостей полезен, но сам по себе не свидетельствует
об отсутствии уязвимостей. Версии фиксируются ради воспроизводимости и
подлежат последующему пересмотру при оценке безопасности.
