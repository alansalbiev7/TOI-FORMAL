# Запуск и границы развёртывания

Поддерживается локальное исполнение через Gradle `installDist` на JDK 17.
См. команды в [README](../README.md). Сборка не требует Redis, PostgreSQL,
Kubernetes или учётной записи облачного провайдера.

Старые манифесты находятся в [design/legacy](../design/legacy/README.md).
Они не обслуживают текущий CLI и не должны применяться как рабочая конфигурация.
CI не публикует образов и не запускает инфраструктуру.

Промышленное развёртывание — отдельный этап: формализовать модель угроз,
роли, интеграционные контракты, доказательный журнал, сроки хранения,
обновления и восстановление; затем провести приёмку. Успешный запуск
лабораторного примера не подтверждает готовность к обработке реальных данных.
