# Процессы исполнения

Lean/Lake и JVM-приложение — независимые локальные процессы.
Первый строит проверенные объявления, второй исполняет выбранные проверки RDF.
Gradle запускает JUnit в тестовой JVM и формирует локальный дистрибутив.
Redis, PostgreSQL, Kubernetes и брокер сообщений в текущем контуре не нужны.
Промышленная схема должна быть разработана отдельно после согласования интерфейсов.
