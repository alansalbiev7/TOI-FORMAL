# Компоненты лабораторного ядра

| Компонент | Ответственность |
|---|---|
| `Artifacts` | Ограниченное чтение, SHA-256, Turtle |
| `Verification` | SHACL, локальный SELECT, явные исходы |
| `Evidence` | Точный состав результатов и привязок |
| `ReleaseGate` | Контекст согласования и применимость |
| `AtomPartition` | Конечный перевод по проверенным блокам |
| `RequirementClosure` | Зависимости, причины и конфликты |

`Main` вызывает только проверку артефактов. Он не утверждает и не исполняет
ведомственные операции.
