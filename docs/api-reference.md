# Интерфейс лабораторного ядра

## CLI

`asg-core DATA.ttl SHAPES.ttl CONSTRAINTS.rq`

Три аргумента — локальные файлы, каждый не более 8 МиБ.
Вывод: три строки `sha256.<роль>=<digest>` и статусы двух проверок с областью
применимости. Полные данные не выводятся в журнал. Коды завершения: 0, 1, 2
описаны в README. Сетевой интерфейс REST/gRPC отсутствует.

## Библиотека Scala

- `Verification.verify`: проверяет граф; ошибки чтения обязательных артефактов
  возбуждают исключение; ошибки движка отражаются как `Error`.
- `Evidence.passes`: требует точного непустого набора проверок без дубликатов.
- `ReleaseGate.admit`: допускает только согласованный точный контекст с хешами.
- `ReleaseGate.usable`: отклоняет отозванное правило либо несовпадение контекста.
- `AtomPartition.checked`: конструирует перевод только при непустых,
  непересекающихся блоках и полном покрытии.
- `RequirementClosure.compute`: вычисляет конечное замыкание, причины добавлений
  и выявленные несовместимости. Замкнутость не означает реализуемость.

Согласования, свидетельства и списки полномочий — доверенные объекты в памяти.
Нельзя превратить этот API в публичный сервис простым добавлением HTTP-обёртки.
