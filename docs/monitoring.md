# Наблюдаемость и измерения

CLI сообщает область проверки, статусы, число нарушений и хеши входов.
Промышленная телеметрия, распределённые трассы и SLO пока не реализованы.

Для последующего стенда отдельно измеряются: доля исполненных согласованных
сценариев, ошибки движка, предметные отказы, неподдерживаемые конструкции,
задержка на заданной нагрузке, время согласования изменения и стоимость
подключения участника. Отказ проверки не объединяется с техническим тайм-аутом.
Показатели связывают с профилем, версией, областью и знаменателем.

Снижение транзакционных издержек проверяется относительно сопоставимой базы:
согласование, разработка преобразований, устранение ошибок, сопровождение.
Повторное использование может снизить издержки, но содержание каталогов и
контроль изменений также требуют затрат. Токеномика и сетевые эффекты не
считаются доказанной экономией. Численные нормативы без протокола не публикуются.
