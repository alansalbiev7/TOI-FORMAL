# Нормативный контекст исследовательского репозитория

Эти файлы описывают область связи программного проекта с предложениями
монографии. Они не являются опубликованными актами, принятыми стандартами
или свидетельствами ведомственного согласования. Полные проекты следует
читать в соответствующей актуальной авторской редакции монографии.

В исходной версии рядом с пометкой «проект» имелись утверждения «внесён»,
«согласован», не подтверждённые материалами. Они исключены из актуальных
описаний. В CI не проверяется соответствие отраслевому праву и процедурам
сертификации; программный результат не создаёт юридических полномочий.
