# Синтетические примеры

Файлы — небольшие учебные словари в синтаксисе Turtle (расширение `.owl`
сохранено исторически). Они не являются официальными онтологиями ведомств.
Внешние импорты отсутствуют. `relatedMatch` обозначает кандидат связи,
а не равенство классов или отождествление людей.

Неподтверждённые утверждения о правовом соответствии и участии ведомств
исключены; исходные заготовки доступны в истории Git. Предметная полнота
и применимость к реальным данным не заявляются. Пример проверки находится
в `examples/valid-mapping.ttl`; связи между словарями не выпускаются автоматически.
