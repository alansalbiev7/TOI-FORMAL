# Предпосылки и формальные обязательства

В новом коде не вводятся непроверенные аксиомы проекта. Условия теорем
передаются как типизированные структуры и доказательства.

| Результат | Условия |
|---|---|
| T1.1 | Две булевы алгебры; сохранение нуля, единицы, пересечения и объединения; отражение нуля |
| Разбиение атомов | Непустые блоки, единственность принадлежности блоку, покрытие целевого носителя |
| ALC-семантика | Явная интерпретация атомов и ролей; биекция доменов с согласованными отношениями |
| T1.2 | Ограниченная решётка; дистрибутивность дополнительно для закона фрейма |
| T2.1 | Три отображения контракта, инъективное кодирование значений, коммутирующее наблюдение |
| T2.2 | Один общий булев перевод и конечный список баз, представленных конъюнкциями |
| T3.1 | Экстенсивный, монотонный, идемпотентный оператор замыкания |

Ни непустой RDF-класс, ни сходство эмбеддингов не удостоверяют эти предпосылки.
Установление мостов между реальными данными и математическими объектами —
самостоятельное обязательство. См. [символы и разделы](../docs/monograph-alignment.md).
