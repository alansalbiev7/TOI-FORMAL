# Сопоставление способов проверки

| Способ | Что даёт | Чего сам по себе не даёт |
|---|---|---|
| Формат/схема | Принадлежность структуре | Предметный смысл |
| SHACL | Выполнение указанных ограничений графа | Все логические следствия OWL |
| SELECT-регрессия | Отсутствие выявленных нарушений выбранного запроса | Сохранение произвольного класса запросов |
| Lean | Доказательство формулы при её предпосылках | Корректность произвольного внешнего кода |
| Испытания | Наблюдаемое поведение заданных сценариев | Универсальная гарантия вне испытанной области |
| Согласование | Решение уполномоченной стороны по установленной процедуре | Математическая истинность преобразования |

Эти способы дополняют друг друга. Универсальный рейтинг продуктов, ускорение
или снижение затрат без сопоставимого эксперимента не приводятся.
