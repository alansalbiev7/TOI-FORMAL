# Термины и различия

| Термин | Значение в репозитории |
|---|---|
| Взаимодействие | Процесс обмена либо взаимного воздействия; сам факт не подтверждает правильность результата |
| Совместимость | Возможность совместного применения в заданных условиях; свойства уточняются контрактом |
| Интероперабельность | Способность участников обмениваться информацией и согласованно использовать её для установленной задачи |
| Профиль | Согласованный набор стандартов, структурированный по эталонной модели |
| Проектный контракт | Сценарий, версии, данные, ограничения, роли и ожидаемый результат применения профиля |
| Кандидат | Предложенное соответствие, ещё не допущенное к применению |
| Свидетельство | Результат конкретной проверки, связанный с точными артефактами и областью |
| Выполнимость | Существование модели и объекта, удовлетворяющего выражению |
| Логическое следование | Истинность включения во всех допустимых моделях |
| Ответ на запрос | Наблюдаемый результат в определённом состоянии и режиме вычисления |
| Объяснение | Доступное пользователю основание результата; может требовать отдельной проверки |

Термины приводятся как рабочие пояснения. Нормативные определения при цитировании
следует сверять с первоисточником. Три уровня ГОСТ не смешиваются с этапами
проверки, уровнями зрелости или архитектурными представлениями.
