# Приложение 1. Глоссарий терминов и сокращений

> Настоящий глоссарий содержит 84 термина, использованных в монографии
> «Технология интероперабельности» (ТОИ). Термины расположены по алфавиту
> (русский алфавит); для каждого термина указаны: полное русское наименование,
> английский эквивалент, общепринятая аббревиатура (если существует) и
> определение из 2–3 предложений. При наличии нескольких значений приводится
> основное (в контексте монографии) и ссылка на дополнительное.

---

## А

**Аккаунт-агент (identity broker)** — *IdP broker* — программный компонент,
обеспечивающий мост между локальными учётными записями и внешним
провайдером идентичности (Keycloak, SAML). В ASG используется для
маршрутизации административных сессий и аутентификации операторов.

**Аксиома онтологической экстенсиональности (OE)** — *ontology
extensionality axiom* — **OE** — утверждение, фиксирующее, что
концептуальная решётка онтологии является полной дистрибутивной решёткой
(OE-1), либо сохранение точных соединений/пересечений (OM-2), либо
сохранение ролевых ограничений (OM-3). Семейство аксиом OE/OM/SS
образует формальное ядро ТОИ (см. §1.3, Прил. 2).

**Атомарный концепт** — *atomic concept* — именованный концепт онтологии,
не разложимый на более простые (через ⊔, ⊓, ∃, ∀). В DL-нотации
обозначается одной буквой `A`; в OWL соответствует классу `owl:Class` без
декларации эквивалентности через `owl:intersectionOf` или
`owl:unionOf`.

## Б

**BERT (Bidirectional Encoder Representations from Transformers)** —
*BERT* — модель машинного обучения на основе Transformer (Devlin et al.,
2019). В ASG используется в качестве fallback-матчера при ранжировании
кандидатов на семантическое соответствие концептов, когда BM25-оценка
ниже порога. Предобученная модель `cointegrated/rubert-tiny2`
дообучается на размеченных парах концептов СМЭВ.

**BM25 (Best Matching 25)** — *BM25* — ранжирующая функция для
полнотекстового поиска (Robertson, Zaragoza, 2009). В ASG используется
`MatcherAgent` для ранжирования кандидатов на семантическое соответствие
по лексическому сходству имён концептов. Порог срабатывания — `0.6`.

## В

**Ведомственная информационная система (ВИС)** — *departmental information
system* — информационная система федерального органа исполнительной власти,
участвующая в межведомственном электронном взаимодействии. Примеры: ИС ФНС,
ИС ФОМС, ИС МВД. ВСЕ ВИС подключаются к СМЭВ-шине.

**Вен-даграмма (Venn diagram)** — *Venn diagram* — графическое
представление логических отношений между подмножествами. В теории решёток
используется для иллюстрации дистрибутивности и подрешёточных запрещённых
конфигураций (M₃, N₅).

**Верхняя грань концептуальной решётки** — *top (universal concept)* —
`⊤` — наибольший элемент решётки концептов `L(O)`, соответствующий
универсальному концепту. В OWL представлен классом `owl:Thing`. В
теореме 1.1 доказывается сохранение верхней грани: `m(⊤) = ⊤`.

## Г

**Гостовский профиль** — *GOST profile* — подмножество аксиом OWL 2,
рекомендуемое для использования в государственных информационных системах
РФ. Соответствует профилю OWL 2 RL с дополнительными ограничениями на
использование `owl:hasKey`, `owl:propertyDisjointWith`, что обеспечивает
полиномиальную сложность вывода.

**Гомоморфизм решёток** — *lattice homomorphism* — отображение
`f : L₁ → L₂` между двумя решётками, сохраняющее операции `⊔` и `⊓`:
`f(a ⊔ b) = f(a) ⊔ f(b)` и `f(a ⊓ b) = f(a) ⊓ f(b)`. В ТОИ — основной
объект аксиомы OM-2.

**ГОСТ Р 55062-2021** — *GOST R 55062-2021* — национальный стандарт
РФ «Информационные технологии. Интероперабельность. Основные положения».
Введён в действие 30.04.2022. Устанавливает общую терминологию и принципы
интероперабельности (см. Прил. 7, 8).

## Д

**Двойственность Пристли** — *Priestly duality* — контравариантная
эквивалентность между категорией дистрибутивных решёток с гомоморфизмами
(`DLat`) и категорией пространств Пристли с непрерывными отображениями
(`Pries`), установленная Х. Пристли в 1970 г. В ТОИ используется для
геометрической интерпретации онтологических морфизмов (см. §1.4,
Прил. 13).

**Декларативная семантика** — *declarative semantics* — способ задания
смысла формул через отношение выполнимости `⊨`, без указания
вычислительной процедуры. В дескрипционных логиках — Tarski-семантика
через интерпретации `I = (Δ^I, ·^I)`.

**Дескрипционная логика (DL)** — *description logic* — семейство
модальных логик, используемых для формального описания предметных
областей через концепты, роли и индивидов. Базовые операторы: `⊑`, `⊔`,
`⊓`, `∃`, `∀`, `¬`, `≥n`, `≤n`. Профили: ALC, SROIQ, OWL 2 RL/EL/DL.

**Дистрибутивная решётка** — *distributive lattice* — решётка, в которой
операции `⊔` и `⊓` дистрибутивны относительно друг друга: `a ⊔ (b ⊓ c) =
(a ⊔ b) ⊓ (a ⊔ c)`. Согласно теореме Биркгофа (1933), решётка
дистрибутивна iff она не содержит подрешёток M₃ или N₅.

## Е

**ЕГИСЗ** — *Единая государственная информационная система здравоохранения*
— *UGISH* — федеральная информационная система Минздрава России,
объединяющая медицинские информационные системы регионов и учреждений.
Подключена к СМЭВ. Одна из трёх пилотных предметных онтологий ASG (см.
`ontologies/healthcare/v1.0.owl`).

**ЕСКС** — *Единая система классификации и стандартизации* — *USCS* —
совокупность правил и регистров, поддерживаемых Росстандартом для
согласования классификаторов и стандартов РФ.

## Ж — З

**Запрос к онтологии** — *ontology query* — формула DL, для которой
проверяется выполнимость в данной интерпретации. Формально: индуктивный
тип `Query` над `Carrier` онтологии (см. `TOI/Axioms.lean`,
Определение 1.5).

**И**

**Идентификатор онтологии** — *ontology identifier* — IRI (URI), который
уникально идентифицирует онтологию в репозитории. В ASG используется
формат `smev:<domain>:<version>` (например, `smev:tax:v1`).

**Инконсистентность концепта** — *concept inconsistency* — состояние, при
котором концепт `C` не имеет экземпляров ни в одной модели онтологии:
`C^I = ∅` для всех `I ⊨ O`. В OWL представлен `owl:Nothing`. Сохранение
инконсистентности — аксиома SS-2'.

**Интерпретация** — *interpretation* — пара `I = (Δ^I, ·^I)`, где `Δ^I` —
непустой домен, `·^I` — функция интерпретации, сопоставляющая каждому
концепту подмножество `Δ^I`, каждой роли — подмножество `Δ^I × Δ^I`,
каждому индивиду — элемент `Δ^I`.

**IRR (Internal Rate of Return)** — *IRR* — внутренняя норма доходности
инвестиционного проекта. В экономической модели ASG используется для
оценки рентабельности внедрения АСШ. Пороговое значение для бюджета РФ —
`12%` (базовая социальная норма дисконта).

## К

**Кардинальное ограничение** — *cardinality restriction* — оператор DL
вида `≥ n r.C` (не менее `n` `r`-последователей в `C`) или `≤ n r.C` (не
более `n`). В OWL представлен `owl:minCardinality`,
`owl:maxCardinality`, `owl:cardinality`.

**Картезианова замкнутая категория (CCC)** — *cartesian closed category* —
категория с конечными произведениями, терминальным объектом и
экспоненциалом. В теореме 1.2 показано, что категория `CLat` полных
решёток **не** является CCC (контрпример Фунамы–Накаямы 1959).

**Контур Hot-L** — *Hot-L tier* — трёхуровневый эскалационный контур ASG:
(1) Hot-L — синхронная SHACL+OWL2RL-валидация; (2) Hot-L+R — асинхронная
SPARQL-верификация с кэшированием; (3) Learner — обучаемый агент для
запросов, не покрываемых первыми двумя уровнями (см. §3.3, Прил. 11).

## Л

**Лемма 1.1** — *Lemma 1.1* — вспомогательное утверждение: сохранение
верхней грани `m(⊤) = ⊤` для сюръективного морфизма, удовлетворяющего
OM-1. Доказательство — в `TOI/Lemmas/TopPreserved.lean`.

**Lean 4** — *Lean 4* — язык программирования и система автоматического
доказательства теорем (Moura, Ullrich, 2021). В ASG используется для
формальной верификации аксиом OE/OM/SS и Теоремы 1.1. Библиотека теорем:
Mathlib4. Сборка: `lake build`.

**LISI (Levels of Information Systems Interoperability)** — *LISI* —
модель уровней зрелости интероперабельности (C4ISR, 1998). 5 уровней:
L0 (изолированная система), L1 (техническая), L2 (синтаксическая),
L3 (семантическая), L4 (прагматическая). Расширение LISI++ добавляет
когнитивный уровень L4.1–L4.3 для ИИ-систем (см. Прил. 8).

**LISI++** — *LISI++* — расширение LISI для ИИ-систем, разработанное в
рамках монографии. Вводит три подуровня уровня L4: L4.1 — онтологическая
интеграция ИИ-систем; L4.2 — коэволюция онтологий; L4.3 — метакогнитивная
согласованность.

## М

**Многоагентная система (MAS)** — *multi-agent system* — программная
архитектура, в которой поведение системы складывается из взаимодействия
нескольких автономных агентов. В ASG — четыре актора (Matcher, Arbiter,
Validator, Learner), координируемых через ArbiterAgent (см. §3.2).

**Морфизм онтологий** — *ontology morphism* — тройка `(m, m_r, m_a)`:
отображение концептов `m : L(O₁) → L(O₂)`, отображение ролей
`m_r : Roles₁ → Roles₂`, отображение индивидов `m_a : Ind₁ → Ind₂`,
удовлетворяющая аксиомам OM-1, OM-2 (или OM-2' для бесконечных),
OM-3 и SS-2' (см. `TOI/Axioms.lean`, Определение 1.7).

**M3, N5** — *M3, N5* — запрещённые подрешётки в дистрибутивных решётках
(по теореме Биркгофа 1933). M₃ — «diamond lattice» с 5 элементами;
N₅ — пентагональная решётка.

## Н

**Национальный стандарт (ГОСТ Р)** — *national standard* — нормативный
документ, утверждаемый Росстандартом в соответствии с ФЗ-162 «О
стандартизации в РФ». Процедура разработки — по ГОСТ Р 1.2-2020.

**Нижняя грань концептуальной решётки** — *bottom (inconsistent concept)*
— `⊥` — наименьший элемент решётки концептов `L(O)`, соответствующий
несогласованному концепту. В OWL — `owl:Nothing`. Сохранение нижней
грани: `m(⊥) = ⊥` — аксиома (v).

**НСУД** — *Национальная система управления данными* — *NSUD* —
перспективная российская платформа согласованного управления данными
государственных информационных систем. Развивается в рамках
национальной программы «Цифровая экономика».

## О

**Объединение концептов** — *union (join)* — операция `C ⊔ D` в DL,
соответствующая логической дизъюнкции. В OWL — `owl:unionOf`. В теории
решёток — операция точного соединения (`sup`).

**Ограничение роли** — *role restriction* — оператор DL, формирующий новый
концепт из существующей роли и концепта-ограничителя: `∃ r.C` или
`∀ r.C`. В OWL — `owl:someValuesFrom` и `owl:allValuesFrom`.

**OM-1** — *OM-1* — аксиома сохранения иерархии: `C ⊑ D ⟹ m(C) ⊑ m(D)`.
Аналог монотонности для отображения решёток. Доказательство
сохранения — через трансфинитную индукцию в `TOI/Lemmas/`.

**OM-2** — *OM-2* — аксиома сохранения точных соединений и пересечений:
`m(C ⊔ D) = m(C) ⊔ m(D)` и `m(C ⊓ D) = m(C) ⊓ m(D)`. Эквивалентна
гомоморфности отображения `m` в категории `DLat`.

**OM-2'** — *OM-2 prime* — усиление OM-2 для бесконечных онтологий:
сохранение направленных соединений `m(⊔ᵢ Cᵢ) = ⊔ᵢ m(Cᵢ)` для любого
направленного множества. Контрмодель — в `TOI/Countermodels/D.lean`.

**OM-3** — *OM-3* — аксиома сохранения ролевых ограничений:
`m(∃ r.C) = ∃ m(r).m(C)` и `m(∀ r.C) = ∀ m(r).m(C)`. Контрмодель —
в `TOI/Countermodels/B.lean`.

**ОМС** — *Обязательное медицинское страхование* — *CHI* — система
обязательного медицинского страхования граждан РФ. Полис ОМС —
идентификатор застрахованного, используется в ЕГИСЗ.

**Онтология** — *ontology* — формальная спецификация концептуализации
(Gruber, 1993). В контексте ТОИ — четвёрка `O = (id, L(O), Roles,
Individuals)`, где `L(O)` — концептуальная решётка.

**OWL (Web Ontology Language)** — *OWL* — семейство языков онтологического
инжиниринга для семантического веба (W3C, 2004, обновлён 2009 — OWL 2).
Профили: OWL 2 RL, OWL 2 EL, OWL 2 DL, OWL 2 Full.

**OWL 2 RL** — *OWL 2 RL* — профиль OWL 2, оптимизированный для
полиномиального вывода через материализацию. Поддерживает ~80 правил
вывода. Используется в `Owl2RlReasoner` компоненте ASG.

**OWL2RL Reasoner** — *OWL2RL Reasoner* — программный компонент
проверки консистентности онтологии по профилю OWL 2 RL. В ASG —
обёртка над Apache Jena Reasoner (`asg-core/src/main/scala/.../verification/Owl2RlReasoner.scala`).

## П

**Пересечение концептов** — *intersection (meet)* — операция `C ⊓ D` в DL,
соответствующая логической конъюнкции. В OWL — `owl:intersectionOf`.
В теории решёток — операция точного пересечения (`inf`).

**Полная дистрибутивная решётка** — *complete distributive lattice* —
дистрибутивная решётка, в которой существуют точные верхние и нижние грани
любого подмножества (включая бесконечные). Дистрибутивность может быть
бесконечной (complete distributivity) или только конечной. В OE-1
достаточно конечной.

**Постоянный фильтр** — *prime filter* — собственный фильтр `F` решётки
`L`, такой что `a ⊔ b ∈ F ⟺ a ∈ F ∨ b ∈ F`. Используется в построении
пространства Пристли `X_L` для дистрибутивной решётки `L`.

**PROV-O** — *PROV-O* — онтология W3C (2013) для представления
происхождения данных (provenance). В ASG используется `ProvORecorder`
для аудита трансляций (см. §3.4).

**p-морфизм** — *p-morphism (bounded morphism)* — отображение фреймов
Крипке, сохраняющее структуру доступности. Понятие введено С. Крипке
(1963), систематизировано ван Бентемом (1976). Контрвариантная
редукция к онтологическим морфизмам — в §1.5, Прил. 13.

**Priestley space** — *Priestley space* — компактное вполне несвязное
пространство с отношением порядка, на котором операции непрерывны.
Двойственный объект к дистрибутивной решётке в двойственности Пристли.

## Р

**Решётка** — *lattice* — частично упорядоченное множество `L`, в
котором для любых двух элементов существуют точная верхняя грань `a ⊔ b`
(sup) и точная нижняя грань `a ⊓ b` (inf). Базовые примеры: булева
решётка `{0, 1}`, цепь `0 < 1 < 2`, булеан `℘(S)`.

**RDF (Resource Description Framework)** — *RDF* — модель данных W3C
(1999) для представления знаний в виде троек `(subject, predicate,
object)`. Сериализации: Turtle, N-Triples, RDF/XML, JSON-LD.

**RDFS (RDF Schema)** — *RDFS* — язык онтологического инжиниринга над RDF
(2004): классы, свойства, иерархия (`rdfs:subClassOf`,
`rdfs:subPropertyOf`), домен и диапазон. Подмножество OWL.

**С**

**Семантическая инвариантность (SS)** — *semantic invariance* — **SS** —
свойство отображения `m` сохранять выполнимость запросов: `O₁ ⊨ q ⟺ O₂ ⊨
m(q)` (SS-1), либо инконсистентность концептов (SS-2'). Ключевая
аксиома ТОИ, отличающая её от обычных matcher'ов.

**СМЭВ** — *Система межведомственного электронного взаимодействия* —
*SMEV* — федеральная интеграционная шина РФ, объединяющая ВИС для обмена
юридически значимыми документами. Действует с 2010 г. (ФЗ-210).
Нормативная основа: Постановление Правительства РФ № 697 (2010).

**SBOM (Software Bill of Materials)** — *SBOM* — машиночитаемый перечень
компонентов программного обеспечения с указанием версий, лицензий и
источников. Стандарты: SPDX, CycloneDX. В ASG — CycloneDX 1.5,
генерация в CI через `anchore/sbom-action` (см. Прил. 9).

**SHACL (Shapes Constraint Language)** — *SHACL* — язык W3C (2017) для
описания структурных ограничений RDF-графов. В ASG — основной механизм
валидации аксиом OM-1, OM-2, OM-3 (см. Прил. 4).

**SHACL-форма (shape)** — *SHACL shape* — конструкция `sh:NodeShape` или
`sh:PropertyShape`, описывающая ограничения на узлы RDF-графа. Свойства:
`sh:targetClass`, `sh:path`, `sh:minCount`, `sh:class`, `sh:severity`
(`sh:Violation` / `sh:Warning` / `sh:Info`).

**SNILS** — *Страховой номер индивидуального лицевого счёта* —
*SNILS* — уникальный идентификатор застрахованного в системе
обязательного пенсионного страхования РФ. Формат: `XXX-XXX-XXX YY` или
`XXXXXXXXX YY` (11 цифр).

**SPARQL** — *SPARQL* — язык запросов к RDF-данным (W3C, 2008, обновлён
2013 — SPARQL 1.1). В ASG — основной механизм верификации аксиом SS-1 и
SS-2' (см. `sparql/ss1-verify.rq`, `sparql/ss2-verify.rq`, Прил. 4).

**SS-1** — *SS-1* — аксиома семантической инвариантности: `O₁ ⊨ q ⟺ O₂ ⊨
m(q)` для любого запроса `q`. Сильнейшая из аксиом семейства SS; в общем
случае алгоритмически неразрешима, проверяется приближённо через
SPARQL.

**SS-2'** — *SS-2 prime* — аксиома двустороннего сохранения
инконсистентности: `O₁ ⊢ C ≡ ⊥ ⟺ O₂ ⊢ m(C) ≡ ⊥`. Слабее, чем SS-1, но
разрешима для OWL 2 RL. Контрмодель — в `TOI/Countermodels/C.lean`.

**Сюръективность морфизма** — *surjectivity of morphism* — условие
`(vi)`: `∀ D ∈ L(O₂), ∃ C ∈ L(O₁), m(C) = D`. Необходимо для сохранения
верхней грани (Лемма 1.1) и для согласованности SS-2'.

## Т

**Теорема 1.1** — *Theorem 1.1* — центральный результат монографии: если
`m : O₁ → O₂` — онтологический морфизм, удовлетворяющий OE-1, OM-1,
OM-2 (или OM-2'), OM-3, (v) и (vi), то `m` обладает семантической
инвариантностью SS-1 (и, следовательно, SS-2'). Доказательство — в
`TOI/Theorems/T11_Finite.lean` (конечный случай) и
`TOI/Theorems/T11_Infinite.lean` (бесконечный случай).

**Теорема Биркгофа о представлении** — *Birkhoff representation theorem*
— утверждение, что любая конечная дистрибутивная решётка `L` изоморфна
решётке нижних множеств `J(L)` множества её неразложимых элементов
(1933). Обобщается двойственностью Пристли на бесконечный случай.

**Точка выхода (end-point)** — *endpoint* — URL, по которому доступен
сетевой сервис. В ASG — `POST /api/v1/translate` (REST) и
`asg.TranslateService/Translate` (gRPC).

**ТЭМ-2021** — *Трёхуровневая эталонная модель интероперабельности 2021* —
*TEM-2021* — модель описания требований к интероперабельности
государственных ИС, включающая три уровня: семантический, технический,
нормативно-правовой. Введена в научный оборот в рамках настоящей
монографии (см. §1.6, Прил. 5).

**Термин-идентификатор IAT** — *IAT identifier* — *Inter-Agency
Terminology identifier* — уникальный идентификатор термина в
межведомственном реестре терминов СМЭВ. Используется для устранения
неоднозначности при автоматическом сопоставлении концептов разных
онтологий.

## У

**Ультрафильтр** — *ultrafilter* — максимальный собственный фильтр
решётки. В булевой решётке — то же, что простой фильтр. В
двойственности Пристли ультрафильтры соответствуют точкам пространства
`X_L`.

**Уточнение концепта (subsumption)** — *subsumption* — отношение `C ⊑ D`
(«`D` уточняет `C`» или «`C` подчиняется `D`»): `C^I ⊆ D^I` для любой
модели `I`. В OWL — `rdfs:subClassOf`.

## Ф

**ФНС** — *Федеральная налоговая служба* — *FTS* — федеральный орган
исполнительной власти РФ, осуществляющий контроль за соблюдением
налогового законодательства. ИС ФНС — одна из трёх пилотных предметных
онтологий ASG (см. `ontologies/tax/v1.0.owl`).

**Фильтр** — *filter* — непустое собственное подмножество `F` решётки
`L`, замкнутое относительно `⊓` и вверх. Тройка условий: `a ∈ F ∧ a ≤
b ⟹ b ∈ F`, `a, b ∈ F ⟹ a ⊓ b ∈ F`, `⊥ ∉ F`.

**ФЗ-149** — *Федеральный закон от 27.07.2006 № 149-ФЗ* — *FL-149* —
«Об информации, информационных технологиях и о защите информации».
Базовый закон РФ в области информационных правоотношений.

**ФЗ-152** — *Федеральный закон от 27.07.2006 № 152-ФЗ* — *FL-152* — «О
персональных данных». Регулирует обработку ПДн в РФ; применим к АСШ в
части трансляции запросов, содержащих ПДн (ИНН, СНИЛС, полис ОМС).

**ФЗ-210** — *Федеральный закон от 27.07.2010 № 210-ФЗ* — *FL-210* — «Об
организации предоставления государственных и муниципальных услуг».
Устанавливает принцип «одного окна» и межведомственного
электронного взаимодействия (СМЭВ).

## X — Ц

**Цепь (chain)** — *chain* — линейно упорядоченное подмножество решётки.
Булеан `℘(S)` содержит максимальную цепь длины `|S|+1`.

## Ч — Ш — Щ

**Шейп-граф (shapes graph)** — *shapes graph* — RDF-граф, содержащий
SHACL-формы. Подгружается в валидатор независимо от данных; в ASG —
файлы из каталога `shapes/*.ttl` (см. Прил. 4).

## Э — Ю — Я

**Экстенсионал запроса** — *query extensional* — подмножество домена
`Δ^I`, на котором запрос `q` выполним в интерпретации `I`. Обозначается
`q.interp I` в формализации Lean 4 (`TOI/Axioms.lean`).

**Akka (Akka Typed)** — *Akka* — инструментарий для построения
распределённых систем на JVM (Scala/Java), основанный на модели акторов.
Версия Akka 2.7.0 (октябрь 2025) возвращена под лицензию Apache 2.0.
В ASG — Akka Typed 2.8.5.

**Apache License 2.0** — *Apache License 2.0* — permissive open-source
лицензия (Apache Software Foundation, 2004). Используется для ASG и всех
сопутствующих артефактов. Совместима с GPLv3; содержит явное
патентное прекращение.

**Apache Jena** — *Apache Jena* — open-source фреймворк Java для работы с
RDF/OWL/SPARQL. В ASG — Jena 4.10.0: `riot` (парсинг), `shacl` (валидация),
`arq` (SPARQL-движок).

**DOI (Digital Object Identifier)** — *DOI* — постоянный идентификатор
цифрового объекта, регистрируемый через Crossref/DataCite. В ASG
DOI-имена присваиваются релизам через Zenodo (см. §5.2, Прил. 12).

**FAIR-принципы** — *FAIR principles* — *FAIR* — набор руководящих
принципов (Wilkinson et al., 2016): Findable, Accessible, Interoperable,
Reusable. 15 подпунктов (4+4+3+4). В ASG — основа политики публикации
артефактов (см. §5.1, Прил. 12).

**FSM (Finite State Machine)** — *FSM* — конечный автомат. В ASG —
основной механизм структурирования поведения `ArbiterAgent` (состояния
S0–S3 и переходы; см. §3.2, Прил. 11).

**HotL (Hot-L contour)** — *Hot-L* — см. «Контур Hot-L».

**ICD-10** — *International Classification of Diseases, 10th Revision* —
Международная классификация болезней 10-го пересмотора (ВОЗ, 1990;
в РФ используется с 1999 г.). Базовый классификатор в
`ontologies/healthcare/v1.0.owl`.

**INN (Идентификационный номер налогоплательщика)** — *INN* —
уникальный идентификатор налогоплательщика в РФ: 12 цифр для физических
лиц, 10 цифр для юридических лиц. В онтологиях ASG — общее свойство
`reg:inn`, `tax:inn`, `health:inn` (см. `cross-domain-mapping.ttl`).

**Mathlib4** — *Mathlib4* — библиотека математики для Lean 4 (Mathlib
Community, 2020+). Содержит формализации теории решёток, категорий,
топологии, алгебры. В ASG — `Mathlib.Order.CompleteLattice`,
`Mathlib.Order.Lattice`, `Mathlib.Data.Set.Basic`.

**NPV (Net Present Value)** — *NPV* — чистая приведённая стоимость
инвестиционного проекта. В экономической модели ASG — основной
критерий эффективности (см. `economics/npv_irr_bcr.py`).

**OWL2RL** — *OWL2RL* — см. «OWL 2 RL».

**Scala 3** — *Scala 3* — функционально-объектный язык программирования
для JVM (Lampepaa, EPFL, 2021+). В ASG — Scala 3.3.3 (LTS), с
использованием `given`/`using`, opaque types, extension methods.

**Turtle (TTL)** — *Turtle* — текстовый формат сериализации RDF (W3C,
2011, обновлён 2014). В ASG — основной формат хранения онтологий и
SHACL-форм. Префиксы объявляются через `@prefix`.

**TRL (Technology Readiness Level)** — *TRL* — шкала уровней готовности
технологии (NASA, 1995; ISO 16290:2013). 9 уровней: TRL-1 (базовые
принципы) — TRL-9 (внедрение). ТОИ-системы соответствуют TRL-6
(пилот) — TRL-7 (опытная эксплуатация).

**Birkhoff 1937** — *Birkhoff 1937* — монография Гаррета Биркгофа «Lattice
Theory», систематизировавшая теорию решёток. Содержит первую
формулировку теоремы о представлении для конечных дистрибутивных
решёток.

## Математические символы

| Символ   | Значение                                |
|----------|-----------------------------------------|
| `⊑`      | уточнение (subsumption)                 |
| `⊔`      | точное соединение (join / sup)         |
| `⊓`      | точное пересечение (meet / inf)       |
| `⊥`      | нижняя грань (несогласованный концепт)  |
| `⊤`      | верхняя грань (универсальный концепт)  |
| `∃ r.C`  | экзистенциальное ограничение по роли r |
| `∀ r.C`  | универсальное ограничение по роли r    |

| `≤ n r.C`| кардинальное ограничение «не более n»  |
| `≡`      | эквивалентность концептов              |
| `⊨`      | семантическое следствие (entailment)    |
| `⊢`      | синтаксическое следствие (deducibility) |
| `L(O)`   | концептуальная решётка онтологии O     |
| `Δ^I`    | домен интерпретации I                  |
| `·^I`    | функция интерпретации                  |
